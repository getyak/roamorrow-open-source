# Roamorrow for iOS

The native app uses SwiftUI, MapKit and Core Location. Its Xcode project is defined
in `project.yml`. Unit tests are in `SoloCompass/Tests`, with UI tests listed in
the project's test targets.

Follow the [iOS setup](../../README.md#ios) to generate the project and run it on
a Simulator. Use your own signing team and unique bundle identifiers to run on a
physical device. Set up your own account backend before testing cloud sync.
